# ADF4159 — Direct Modulation / Fast Waveform Generating, 13 GHz Fractional-N Frequency Synthesizer (PLL)

**Source PDF:** `datasheets/ADF4159.pdf` (Rev. E, 7/2014, 36 pages). Downloaded from Farnell mirror (farnell.com/datasheets/2253221.pdf) after analog.com media host timed out. Content verified as full ADI Rev E datasheet.
**Package:** 24-lead LFCSP_WQ, 4 mm × 4 mm (CP-24-10). (p.1, p.36)
**Role in Rev C:** PLL / FMCW ramp generator. On-chip 3rd-order Σ-Δ fractional-N (25-bit modulus) + PFD + charge pump. Charge pump (CP, pin 24) → external loop filter → ADF5901 VTUNE. RF feedback (RFinA/RFinB) from ADF5901 AUX (÷2, 12 GHz). Generates sawtooth/triangle chirps without a DDS. (p.1, p.35)

## Package + exposed pad + land pattern (Fig.56 p.36; PCB guideline p.34)
- Body: 4.00 mm SQ (3.90–4.10), 24-lead LFCSP_WQ (CP-24-10), JEDEC MO-220-WGGD-8.
- Height 0.80 max (0.70–0.80); standoff 0.05 max.
- Lead pitch 0.50 BSC; width 0.25 (0.20–0.30); length 0.40 (0.30–0.50).
- **Exposed pad: 2.10 mm SQ (2.00–2.20).** EP-to-lead clearance 0.25 min. EP connects to **AGND** (not GND).
- **ADI recommended land pattern (p.34, "PCB Design Guidelines for the Chip Scale Package"):** PCB land 0.1 mm longer than package land length and 0.05 mm wider than package land width; center land on pad. Thermal pad on PCB at least as large as package EP, ≥0.25 mm clearance to inner edges of pad pattern. Thermal vias on 1.2 mm pitch grid, via drill 0.30–0.33 mm, barrel plated with 1 oz copper; connect PCB thermal pad to AGND.

## Supply rails and max currents (Table 1, p.4; Table 4, p.7)
- **AVDD = VP = 2.7 to 3.45 V** (VP must be ≥ AVDD).
- **DVDD = SDVDD = 1.62 / 1.8 / 1.98 V** (1.8 V digital rail).
- Currents (f_PFD = 110 MHz): AIDD (AVDD) 26 mA typ / 40 mA max; DIDD (DVDD) 7.5 mA typ / 10 mA max; IP (VP) 5.5 mA typ / 7 mA max. Power-down 2 µA. (Table 1, p.4)
- Abs max: AVDD to GND −0.3 to +3.9 V; DVDD to GND −0.3 to +2.4 V; VP to GND −0.3 to +3.9 V, VP to AVDD −0.3 to +0.3 V; T_j 150 °C; θ_JA 56 °C/W (24-lead LFCSP, EP soldered to AGND); reflow peak 260 °C. ESD: HBM 3000 V, CDM 1000 V. (Table 4, p.7; Table 5, p.7)

## Operating ranges (Table 1, p.4)
- RF input frequency: 0.5 to 13 GHz (−10 dBm to 0 dBm; ≥400 V/µs slew for lower freq; 8/9 prescaler for higher). Prescaler output ≤2 GHz. (In Rev C fed by ADF5901 AUX ÷2 ≈ 12 GHz.)
- **REFIN input frequency: 10 to 260 MHz** (−5 dBm min to +9 dBm max, biased at 1.8/2 for ac coupling; <10 MHz needs dc-coupled CMOS square wave >25 V/µs). With reference doubler enabled: **10 to 50 MHz** (DB20=1 in R2). Input C 1.2 pF, I ±100 µA. (Table 1, p.4)
- **PFD frequency: 110 MHz max.** (Table 1, p.4)
- Charge pump: I_CP high 4.8 mA (R_SET=5.1 kΩ), low 300 µA; R_SET range 4.59/5.1/5.61 kΩ; three-state leakage 1 nA. (Table 1, p.4)
- Logic: V_IH ≥1.17 V, V_IL ≤0.4 V; V_OH DVDD−0.4 V (CMOS). Normalized phase noise floor: **−224 dBc/Hz (integer-N)**, −217 (fractional-N); 1/f noise −120 dBc/Hz @10 kHz normalized to 1 GHz. (Table 1, p.4–5)
- Write timing (Table 2, p.5): LE setup 20 ns, DATA setup/hold 10 ns, CLK high/low 25 ns, CLK-to-LE 10 ns, LE pulse 20 ns. Read timing Table 3, p.6.

## MUXOUT modes (p.12, Fig.22)
Controlled by M4:M1 bits in Register R0. Selectable outputs: three-state, DVDD, DGND, R-divider output, N-divider output, digital lock detect, serial data output, CLK divider output, R-divider/2, N-divider/2, readback-to-MUXOUT (for frequency/register readback). (p.12)

## Register map summary (p.13–24)
- **8 registers R0–R7.** Register selected by control bits C3:C1 = DB2:DB0. (Table 7, p.12)
- **R0** FRAC/INT register: 12-bit INT (23–4095), MSB FRAC, ramp-on, MUXOUT select. (p.15)
- **R1** LSB FRAC register (13-bit LSB FRAC), phase value. (p.16)
- **R2** R-divider register: 5-bit R counter (1–32), reference doubler (DB20), reference divide-by-2 (DB21), charge-pump current setting, CLK1 divider, cycle-slip-reduction enable (DB28). (p.17)
- **R3** function register: ramp mode, PD polarity, counter reset, power-down, LOL/LDP, negative bleed. (p.19)
- **R4** clock register: CLK1/CLK2 dividers, CLK divider mode, ramp status. (p.21)
- **R5** deviation register: freq deviation word + deviation offset, DEV SEL. (p.22)
- **R6** step register: 20-bit step word, STEP SEL. (p.23)
- **R7** delay register: 12-bit delay start word, delay/triangle/fast-ramp/ramp-delay/delayed-start controls. (p.24, Fig.32)
- Double-buffered settings (write to register then to R0 to take effect): LSB FRAC, phase, CP current, ref ÷2, ref doubler, R counter, CLK1 divider. (p.12)
- RF synth (Eq.2/4, p.11/25): RF_OUT = (INT + FRAC/2^25) × f_PFD; f_PFD = REFIN × (1+D)/(R×(1+T)). f_RES = f_PFD/2^25. Worked example: 12.102 GHz from 100 MHz REFIN → f_PFD=100 MHz, N=121, FRAC MSB=81, FRAC LSB=7536. (p.25)

## Power-up / initialization sequence (p.25)
1. R7 (delay). 2. R6 (step — load twice: STEP SEL=0 then STEP SEL=1). 3. R5 (deviation — load twice: DEV SEL=0 then =1). 4. R4 (clock — load twice: CLK DIV SEL=0 then =1). 5. R3 (function). 6. R2 (R divider). 7. R1 (LSB FRAC). 8. R0 (FRAC/INT). (p.25)

## Application-circuit values (from EV-RADAR-MMIC2 UG-866; see ev-radar-mmic2.md)
- **RSET (R17) = 5.1 kΩ** to GND → I_CP_MAX = 4.8 mA. (UG-866 Fig.11, BOM Table 2)
- REFIN ac-coupling: C17 = 1 nF, C19 = 1 nF, series resistor R96. (UG-866 Fig.11)
- Per-rail decoupling AVDD/DVDD/VP: C3/C4/C5, C6/C7, C10/C11 (0.1 µF + 1 nF + 10 pF triads). (UG-866 Fig.11)
- **Loop filter (CPOUT → VTUNE), passive, 3rd-order (UG-866 Fig.12, BOM Table 2):**
  - R19 = 1 kΩ (series from CP), R20 = 0 Ω (series to VTUNE), R18 = 510 Ω.
  - C12 = 220 pF, C13 = 3.3 nF, C14 = 100 pF.
  - This is the ADI eval-board loop filter for a ~200 MHz ramp using the ADF5901 12 GHz AUX feedback; **re-run ADIsimPLL for the Rev C chirp bandwidth/ramp time before committing values.**
- Phase-detector polarity = negative when using an inverting active loop filter; eval uses passive filter → positive. (UG-866 p.9)

## FMCW application topology (Fig.55, p.35; ADF5901 Fig.31)
Reference oscillator (100 MHz TCXO) → ADF4159 (linear freq sweep) → VCO (ADF5901). ADF4159 CP → loop filter → ADF5901 VTUNE. ADF5901 AUX (÷2, 12 GHz) → ADF4159 RFinA/RFinB feedback. No DDS required. (p.35)

## Spec deltas
- **ADF4159 is a 24-lead LFCSP (4×4 mm), EP = 2.10 mm SQ, EP tied to AGND** (not the 5×5/GND assumption implicit in the other MMICs). Do not copy the ADF5901/5904 land — this is a smaller distinct footprint. (Fig.56, p.36)
- **REFIN range 10–260 MHz matches the ADF5901 REFIN range**; both share the 100 MHz TCXO on the eval board. With reference doubler enabled REFIN is limited to 10–50 MHz. PFD max 110 MHz. (Table 1, p.4)
- Digital rail is **1.8 V (DVDD/SDVDD)**, distinct from the 3.3 V analog rails — the two-LDO "both 3.3 V" spec assumption is incomplete: the eval board actually uses **three** regulators feeding this chip's domain (ADP150 3.0 V for AVDD_PLL, ADP150 1.8 V for DVDD_PLL) plus the ADP7104 3.3 V rails for the MMICs. See ev-radar-mmic2.md Spec deltas. (Table 1 p.4; UG-866 Fig.14)
- Chirp 24.150–24.250 GHz is a VCO-output band; ADF4159 itself operates on the ~12 GHz AUX feedback (÷2) — well within its 0.5–13 GHz RF input range. No contradiction. (Table 1, p.4)
