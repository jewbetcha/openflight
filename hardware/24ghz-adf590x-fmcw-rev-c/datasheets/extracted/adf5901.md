# ADF5901 — 24 GHz VCO + PGA with 2-Channel PA Output (Tx MMIC)

**Source PDF:** `datasheets/ADF5901.pdf` (Rev. A, 7/2016, 26 pages). Downloaded from Farnell mirror (farnell.com/datasheets/2153191.pdf) after analog.com media host timed out; content verified as full ADI Rev A datasheet.
**Package:** 32-lead LFCSP_WQ, 5 mm × 5 mm (CP-32-12). (p.1, p.26)
**Role in Rev C:** 24 GHz Tx MMIC. On-chip VCO generates the 24 GHz chirp for two Tx channels **and** the LO output that drives the ADF5904 receiver. VTUNE driven by ADF4159 charge-pump loop filter. (p.1, p.25 Fig.31)

## Package + exposed pad + land pattern (Fig.32, p.26)
- Body: 5.00 mm SQ (4.90–5.10), 32-lead LFCSP_WQ (CP-32-12), JEDEC MO-220-WHHD-5. Very very thin quad.
- Height: 0.80 max (0.70–0.80); standoff 0.05 max.
- Lead pitch: 0.50 BSC. Lead width 0.25 (0.18–0.30). Lead length 0.40 (0.30–0.50).
- **Exposed pad: 3.60 mm SQ (3.55–3.75).** EP-to-lead clearance 0.25 min.
- ADI does not print a separate recommended land drawing in this datasheet; use the package outline (0.50 pitch, EP 3.60 sq) with standard LFCSP land rules. Pair with ADF4159 datasheet PCB guideline (land 0.1 mm longer / 0.05 mm wider than package land; EP thermal-via 1.2 mm grid) as the ADI-recommended CSP practice for this family.

## Supply rails and max currents (Table 1, p.3; Table 3, p.6)
- All rails AHI = TX_AHI = RF_AHI = VCO_AHI = DVDD: **3.135 / 3.3 / 3.465 V** (3.3 V ±5%). Must be tied to same value.
- **Total current I_TOTAL = 170 mA typ** (T_A=25 °C, AHI=3.3 V, f_REFIN=100 MHz, RF=24.125 GHz). (Table 1, p.3, footnote 1)
- Software power-down: 500 µA typ. Hardware power-down: 200 µA typ.
- Abs max: AHI to GND −0.3 to +3.9 V; VTUNE to GND −0.3 to +3.6 V; digital I/O −0.3 to DVDD+0.3 V; T_j 150 °C; θ_JA 40.83 °C/W; reflow peak 260 °C. ESD: HBM 2000 V, CDM 250 V. (Table 3, p.6)

## Operating ranges / output power
- **RF frequency range: 24 to 24.25 GHz.** (Table 1, p.3, Operating Conditions) — chirp band edge (see Spec deltas).
- VTUNE: 1 to 2.8 V (impedance 100 kΩ). (Table 1, p.3)
- **Tx output power: 2 / 8 / 10 dBm (min/typ/max), 50 Ω, single-ended.** On/off isolation 30 dB, Tx-to-Tx 25 dB, power up/down 200 ns. (Table 1, p.3)
- **LO output power: −7 / −1 / +5 dBm (min/typ/max), 50 Ω.** On/off isolation 30 dB. (Table 1, p.3) — this feeds ADF5904 LO_IN (−8 to +5 dBm range → in-range).
- AUX output: −9/−5/0 dBm single-ended; ÷2 = 12–12.125 GHz, ÷4 = 6–6.0625 GHz, 200 Ω differential. (Table 1, p.3)
- REFIN: **10 MHz to 260 MHz**, −5 dBm min to +9 dBm max, biased at AHI/2 (ac-coupled); <10 MHz needs dc-coupled CMOS square wave, slew >25 V/µs. Input C 1.2 pF, I ±100 µA. (Table 1, p.4)
- Logic: V_IH ≥1.4 V, V_IL ≤0.6 V. ADC: 8-bit, LSB 7.4 mV. Temp sensor ±5 °C, 6.4 mV/°C. (Table 1, p.4)
- Write timing (Table 2, p.4): LE setup 20 ns, DATA setup/hold 10 ns, CLK high/low 25 ns each, CLK-to-LE 10 ns, LE pulse 20 ns.

## Register map summary (Register Maps p.13–23)
- **12 registers R0–R11.** Register selected by control bits C5:C1 = DB4:DB0 in each 32-bit word. (Table 5, p.13)
- R0 (C=00000): power/VCO calibration control (Tx1/Tx2/LO power, amplitude cal). R1: Tx amplitude level. R2: ADC clock. R3: IO level (VDD 3.3 V), ADC output routing. R4: ATEST/analog-test-bus config. R5: INT + MSB FRAC. R6: LSB FRAC. R7: master reset, R-counter clock, calibration clock, reference doubler(D)/divide-by-2(T). R8: frequency-cal divider (10 µs time base). R9. R10. R11: counter reset (DB5). (p.15–23)
- RF synth (Eq.5, p.24): RF_OUT = (INT + FRAC/2^25) × f_REF × 2; f_REF = REFIN × (1+D)/(R×(1+T)). Worked example: 24.125 GHz from 100 MHz REFIN → f_REF=50 MHz, N=241, FRAC MSB=1024, FRAC LSB=0. (p.24)

## Power-up / initialization sequence (p.23, 21 steps)
1. R7 = 0x02000007 (master reset). 2. R11 = 0x0000002B (reset counters). 3. R11 = 0x0000000B (enable counters). 4. R10 = 0x1D32A64A. 5. R9 = 0x2A20B929. 6. R8 = 0x40003E88 (freq cal clock 100 kHz). 7. R0 = 0x809FE520 (power up device + LO, 10 µs). 8. R7 = 0x011F4827 (R-counter clk 50 MHz, cal clk 100 kHz). 9. R6 = 0x00000006 (LSB FRAC=0). 10. R5 = 0x01E28005 (INT=241, MSB FRAC=1024 → N=240.25). 11. R4 = 0x00200004 (ATEST high-Z). 12. R3 = 0x01890803 (IO level 3.3 V). 13. R2 = 0x00020642 (ADC clock 1 MHz). 14. R1 = 0xFFF7FFE1 (Tx amplitude). 15. R0 = 0x809FE720 (VCO freq cal, 800 µs). 16. R0 = 0x809FE560 (Tx1 on, Tx2 off, LO on). 17. R0 = 0x809FED60 (Tx1 amp cal 400 µs). 18. R0 = 0x809FE5A0 (Tx1 off, Tx2 on, LO on). 19. R0 = 0x809FF5A0 (Tx2 amp cal 400 µs). 20. R9 = 0x2800B929. 21. R0 = 0x809F25A0 (disable R and N counters). (p.23)
Recalibration sequence (every 10 °C) and temperature-sensor readback sequence also given on p.23–24.

## Application-circuit values (from EV-RADAR-MMIC2 UG-866; see ev-radar-mmic2.md)
- RSET (R22) = 5.1 kΩ to GND. (UG-866 BOM Table 2; Fig.13 p.16)
- Per-rail decoupling triad 0.1 µF + 1 nF + 10 pF (UG-866 Fig.13). REFIN ac-coupling C1/C2 = 1 nF (UG-866 Fig.13, BOM).
- C1 pin (pin 31) 47 nF, C2 pin (pin 32) 220 nF, VREG 220 nF — per datasheet pin descriptions (p.8) and eval decoupling.
- Tx outputs (TXOUT1/2) and LO carry a dc bias → **must be ac-coupled** off-chip. (UG-866 p.5 "RF Output Signals"; datasheet Fig.31)

## FMCW application topology (Fig.31, p.25)
ADF4159 CP → loop filter → ADF5901 VTUNE. ADF4159 RFinA/RFinB ← ADF5901 AUX/AUX (÷2 = 12 GHz feedback). ADF5901 TXOUT1/2 → Tx antennas. **ADF5901 LOOUT → ADF5904 LO_IN.** ADF5904 RX baseband → ADAR7251 (eval uses ADAR-D2S/AD8129) → DSP. (p.25)

## Spec deltas
- **Total Tx-MMIC current is 170 mA typ**, not the spec's "~250 mA class for ADF5901." The spec's per-rail 250 mA class is a conservative over-estimate; real draw for the whole ADF5901 (all four 3.3 V rails combined) is ~170 mA typ, ~200 mA max-ish over temp. LDO sizing at 250 mA is safe but generous. (Table 1, p.3)
- **ADF5901 RF range is 24.00–24.25 GHz.** The chirp band 24.150–24.250 GHz sits inside this but the upper chirp edge (24.250) is exactly the datasheet max. Fig.11 (p.10) shows VTUNE frequency range extends above 24.25 but the "specified range" shading ends at 24.25 GHz; operation to 24.25 is in-spec, no margin above. Flag: chirp must not exceed 24.250 GHz. (Table 1 p.3; Fig.11 p.10)
- **PA output +8 dBm typ confirmed** (matches spec assumption); min 2 dBm, max 10 dBm. (Table 1, p.3)
- **LO output drives ADF5904 in range**: ADF5901 LOOUT −7/−1/+5 dBm vs ADF5904 LO input −8 to +5 dBm. Typical −1 dBm is comfortably inside; **at the −7 dBm low corner it is still above the ADF5904 −8 dBm min, but only by 1 dB** — verify trace/connector loss between LOOUT and LO_IN stays under ~1 dB or LO could drop below the ADF5904 minimum. (ADF5901 Table 1 p.3; ADF5904 Table 1 p.3)
