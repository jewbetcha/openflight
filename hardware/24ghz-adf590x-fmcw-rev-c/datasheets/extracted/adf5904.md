# ADF5904 — 4-Channel, 24 GHz Receiver Downconverter (Rx MMIC)

**Source PDF:** `datasheets/ADF5904.pdf` (Rev. A, 2/2016, 15 pages). Downloaded from Farnell mirror (farnell.com/datasheets/2177306.pdf) after analog.com and Mouser hosts refused (Mouser returned an access-denied HTML page). Content verified as full ADI Rev A datasheet.
**Package:** 32-lead LFCSP_WQ, 5 mm × 5 mm (CP-32-12). (p.1, p.15)
**Role in Rev C:** 24 GHz 4-channel receiver. Four single-ended RF inputs (on-chip baluns → LNA → downconvert mixer → differential baseband). Single shared LO path with on-chip balun. LO_IN driven by ADF5901 LOOUT. (p.1)

## Package + exposed pad + land pattern (Fig.22, p.15)
- Body: 5.00 mm SQ (4.90–5.10), 32-lead LFCSP_WQ (CP-32-12), JEDEC MO-220-WHHD-5 (except EP dimension).
- Height 0.80 max (0.70–0.80); standoff 0.05 max.
- Lead pitch 0.50 BSC; width 0.25 (0.18–0.30); length 0.40 (0.30–0.50).
- **Exposed pad: 3.60 mm SQ (3.55–3.75).** EP-to-lead clearance 0.25 min.
- Same package family/footprint as ADF5901; reuse the same LFCSP land (0.50 pitch, EP 3.60 sq). No separate recommended-land drawing printed; use ADI CSP land rule (see ADF4159 PCB guideline).

## Supply rails and max currents (Table 1, p.3; Table 3, p.5)
- **AVDD single rail: 3.3 V ±5% (pins 4, 21, 27 all one net).**
- **AVDD current = 170 mA typ.** Power-down current 100 µA. (Table 1, p.3, Power Supplies)
- Abs max: AVDD to GND −0.3 to +3.9 V; RXx_RF and LO_IN to GND −0.3 to AVDD+0.3 V; T_j 150 °C; θ_JA 40.83 °C/W; reflow peak 260 °C. ESD: HBM 2000 V, CDM 500 V. (Table 3, p.5)

## Operating ranges / LO input (Table 1, p.3)
- **LO and RF frequency range: 24 to 24.25 GHz.** (Operating Conditions)
- **LO input level: −8 dBm min / −5 dBm typ / +5 dBm max.** LO input return loss (S11) −5 dB. (LO Input)
- Rx channel gain 22 dB (voltage conversion gain, differential). Demodulation bandwidth 10 MHz (max load cap 10 pF). Output DC offset ±20 mV. Output common mode AVDD−1.0 V. **Output swing 2 V peak into 900 Ω differential load.** Channel-to-channel phase mismatch ±5°. (Table 1, p.3)
- Dynamic: conversion gain 22 dB, input P1dB −10 dBm, RF input return loss −5 dB, IIP2 20 dBm, IIP3 0 dBm, LO-to-RF isolation 30 dB, RF-to-IF isolation 30 dB, **noise figure 10 dB (DSB)**, NF under blocking 15 dB. (Table 1, p.3)
- **Rx output impedance: 900 Ω differential.** (Features p.1; Table 1)
- Logic: V_IH ≥1.4 V, V_IL ≤0.6 V; DOUT level selected by DB8 (Reg 0) = 3.3 V or 1.8 V. Temp sensor ±5 °C, 4.243 mV/°C. (Table 1, p.3)
- Timing (Table 2, p.4): LE setup 20 ns, DATA setup/hold 10 ns, CLK high/low 25 ns, CLK-to-LE 10 ns, LE pulse 20 ns.

## RF / LO input stage (Theory of Operation, p.9)
- **RF input stage (Fig.15):** single-ended RXx_RF into on-chip balun; on-chip 2 kΩ + 2 kΩ bias network on differential side → LNA. AVDD-referenced ESD/bias.
- **LO input stage (Fig.16):** single-ended LO_IN into on-chip balun; 20 Ω/20 Ω and 400 Ω/400 Ω on-chip bias resistors. **AC-couple the LO signal to LO_IN.** LO_IN dc bias is programmable (Reg 0 DB9: 0 = no dc bias, 1 = 1.5 V dc bias). (p.9, p.11)

## Register map summary (p.10–12)
- **4 registers R0–R3.** Register selected by control bits C2:C1 = DB1:DB0. (Table 5, p.9)
- **R0 (C=00):** PUP CH1–CH4 (DB11–DB14, power-up per RF channel), PUP LO (DB10), LO_IN pin bias (DB9: 1.5 V dc bias enable), DOUT VSEL (DB8: 3.3 V/1.8 V logic). (Fig.18, p.11)
- **R1 (C=01):** channel internal controls + LO path config; CHANNEL SELECT bits CS2:CS0 (DB31:DB29): 000 none, 001 CH1, 010 CH2, 011 CH3, 100 CH4, 101 LO, others reserved. (Fig.19, p.12)
- **R2 (C=10):** 5-bit channel test select TC4:TC0 (DB14:DB10) — temp-sensor-to-ATEST and register readback modes (R0/R1-per-channel/R1-LO/R2 readback on DOUT). (Fig.20, p.12)
- **R3 (C=11):** reserved. (Fig.17, p.10)

## Application-circuit values (from EV-RADAR-MMIC2 UG-866; see ev-radar-mmic2.md)
- AVDD decoupling triad 0.1 µF + 1 nF + 10 pF per pin (UG-866 Fig.23 RX12_AHI/RX34_AHI/LO_AHI banks). RF inputs (RXx_RF) carry dc bias → **ac-couple** each RF input; LO_IN also ac-coupled. (UG-866 p.5)
- Baseband outputs feed differential receiver amps: eval uses AD8130ARZ (ADAR-D2S) at gain 1 (RF=0, RG=NC) or gain 10 (RF=560 Ω, RG=62 Ω), 1 µF ac-coupling and 100 pF/10 pF supply decoupling. Datasheet application (Fig.21, p.14) shows ADAR7251 Σ-Δ ADC in the production path. (UG-866 Fig.25–28)

## Spec deltas
- **ADF5904 AVDD current is 170 mA typ**, single 3.3 V rail. Combined with ADF5901 (170 mA) the two MMICs draw ~340 mA typ; ADF4159 adds ~26+7.5+5.5 ≈ 39 mA (see adf4159.md). Total RF/synth active-device draw ~380 mA typ — **below the spec's ~600 mA-from-5V budget.** After LDO dropout/efficiency (linear 3.3 V from 5 V) and the TLV320ADC3140 + level shifters + margin, ~600 mA at 5 V is a reasonable but comfortable headroom estimate; not contradicted. (Table 1, p.3)
- **LO input range −8 to +5 dBm matches the spec assumption exactly.** ADF5901 LOOUT typ −1 dBm is well inside; low corner −7 dBm leaves only ~1 dB above the −8 dBm min — keep LOOUT→LO_IN interconnect loss under ~1 dB. (Table 1, p.3)
- **384 kHz+ sample rate is not an ADF5904 parameter** — the ADF5904 baseband is analog (10 MHz demod BW) into a 900 Ω differential load; sample rate is set by the TLV320ADC3140. No contradiction; noted so downstream tasks size the anti-alias/baseband stage for the ADC, not the Rx MMIC.
- Chirp band 24.150–24.250 GHz is inside the 24.00–24.25 GHz operating range; upper edge is at the datasheet max (no margin above 24.25 GHz). (Table 1, p.3)
