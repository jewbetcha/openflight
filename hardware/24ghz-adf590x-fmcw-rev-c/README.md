# 24 GHz Active FMCW Radar — Rev C

This is an active FMCW two-board radar design for OpenFlight, replacing the Rev B2 passive RX array. It is authored natively in KiCad (the `generate_designs.mjs` pipeline is retired for Rev C).

**Specification:** [ADF590x Active FMCW Radar Rev C Design](../../docs/superpowers/specs/2026-07-01-adf590x-active-fmcw-rev-c-design.md)

## Status

- **Current:** In design, not ordered.
- **Validation:** KiCad ERC/DRC plus KiCad-skill analyzers certify design intent and fabricability.

## Band Plan

**TX 24.150–24.250 GHz, ≥25 MHz below/above nothing — OPS243 at 24.125 GHz stays outside the chirp band.**

The Rev C chirp occupies the upper ISM band with a 25 MHz guard band from the OPS243-A CW carrier, ensuring coexistence in both directions: Rev C's receiver is far outside the OPS's 50 kHz Doppler baseband, and OPS energy lands ≥25 MHz away in the Rev C baseband, well outside the ~100 kHz anti-alias corner.

## Design Boundaries

### RF Board (hybrid Rogers, ~70 × 50 mm)

- **RX array:** Four 2×2 patch subarrays in a 2×2 grid at ~1 lambda pitch (azimuth + elevation pair).
- **TX antenna:** Single series-fed 1×4 patch column (~10–11 dBi) on ADF5901 TX1, isolated from RX via stitched via fence.
- **Chipset:** ADF5901 (TX + LO), ADF5904 (4-channel RX), ADF4159 (PLL/ramp generator).
- **Stackup:** 4-layer hybrid, 10 mil RO4350B core (L1–L2), FR4 below. Impedance controlled: 50 Ω microstrip on L1 referenced to L2.

### ADC/Pi Interface Board (FR4)

- **ADC:** TLV320ADC3140 configured for 384 kHz capture in I2S/TDM mode (bit-exact, no resampling).
- **Anti-alias:** Scaling/filtering for ~100 kHz beat baseband; values reserved pending first measured ADF5904 levels.
- **Interface:** 2×15 SMD header (1.27 mm pitch) carrying 8 baseband channels (differential pairs), SPI control, power, and RAMP_SYNC GPIO.

## Fabrication Gates

Before ordering PCB:

1. **Datasheet sync:** ADF5901, ADF5904, ADF4159, TLV320ADC3140 pin-level schematic verification against ADI reference design.
2. **PCBWay stackup confirmation in writing** (hybrid RO4350B core + FR4) with exact dielectric heights and Dk/Df before any antenna dimension is frozen.
3. **EM simulation:** HFSS patch calculations validated against the PCBWay-confirmed stackup.
4. **VNA coupon:** Panelized test coupon with main board for in-house impedance measurement.

## Bring-Up

1. Verify PCB assembly and probe SPI control lines to the ADI chips.
2. Configure ADF4159 in fixed CW mode at 24.200 GHz (no ramps) for initial Doppler and angle-of-arrival validation.
3. Enable FMCW mode once baseband levels and raw I2S capture are confirmed.

## Design Assumptions (Rev C Interim)

- Rogers RO4350B: 10 mil core, design Dk 3.66, Df 0.0037.
- **Any delta in the PCBWay-returned stackup table triggers re-running antenna and RF sims** (Tasks 5–8 in the project plan).
